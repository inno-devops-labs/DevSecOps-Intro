`readOnlyRootFilesystem: true` likely broke Juice Shop. What paths did it need to write? How did you fix it (which `emptyDir` mounts)?

`readOnlyRootFilesystem: true` broke Juice Shop because the application needs to write temporary files to `/tmp` and logs to `/usr/src/app/logs`. To fix it, I added two `emptyDir` volumes at these paths, allowing the application to write while keeping the root filesystem read-only.
```yaml
volumes:
    - name: tmp
      emptyDir: {}
    - name: logs
      emptyDir: {}
```
