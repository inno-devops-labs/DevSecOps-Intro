# CPS 5981 Lab 5 — ready-to-edit submission files

This package contains the written artifacts drafted from the actual Unit 05 lab instructions and the supplied worked-example scenario. The text is filled in with concrete architecture, threat, invariant, control, and test reasoning; it is not a bundle of blank templates.

## Put the files in your repository

Copy the `submissions/unit05/` folder into your `feature/lab5` branch in `balouchn/DevSecOps-Intro`. Keep the existing `architecture-v2.md` only if you merge its useful content into the version in this package.

## Three things that must still come from your actual work

1. Export `architecture-v2.png` and `threat-model.json` from OWASP Threat Dragon after you build the DFD.
2. Run Threagile against the actual baseline and hardened YAML models and replace the worked-example counts in `threat-register.md` with your actual report results.
3. Capture the real local scan/test output. `peer-review-received.md` and `dispositions.md` must reflect the real peer review; the review-given file is a prepared set of five substantive findings to adapt to your partner’s actual artifacts.

The assignment explicitly requires actual evidence for controls and negative tests. For that reason, this package does not invent tool logs or attribute fictional classmates’ comments to your review. The written reasoning is drafted; only tool-generated exports, run evidence, and actual peer-review-specific details remain dependent on those activities.
